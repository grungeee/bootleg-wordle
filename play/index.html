01 / HOW IT STARTED

The first thing I ever programmed myself.

This was the first project I programmed entirely myself. I came up with the visual design too. I liked playing the game, and wanted to make my own version in HTML, CSS and JavaScript.

The format comes from Wordle. My part was building my own version and giving it its own look: lavender, chunky tiles and bright colours. This is the first chapter of my portfolio because it is a real part of how I started making things with code.

02 / THE LATER VERSION

Revisited with AI at my side.

I later revisited the game with AI-assisted development. Today's version includes rebuilt game logic, saved daily progress, statistics and interface polish, while keeping the original visual identity. The first version was my own code and design; this later version also includes AI-assisted work.

The rules

Green means the letter is in the right spot, yellow means it is in the word somewhere else, grey means no unused copy remains in the answer. Exact matches are scored first, then the remaining letters, so repeated letters are counted correctly.

No server

Today's word is a hash of the date, so every visitor gets the same puzzle without a backend. Progress, streaks and the guess distribution stay in local storage on your own device, and nothing is sent anywhere.

Two keyboards

Playable from a physical keyboard or the on screen one. Native dialogs handle focus and escape, motion respects your system setting, and every control is a real button.

KNOWN LIMITS

Stats live in your browser, so they do not follow you between devices. The answer pool is filtered down to common words: a puzzle should not be lost to an obscure one.

How to play

Guess the word in 6 tries.

Each guess must be a real 5 letter word. Hit enter to submit.

After each guess the tiles change colour to show how close you were.
