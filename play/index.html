YOUR VISIT DATA, YOUR CHOICE

Optional visit stats: device type, OS, country from your IP, page loads, page time and feature counts. No ads, fingerprinting or analytics cookies. Raw IPs are not saved.

What is stored, and for how long?

Daily guesses, personal game stats and theme stay in this browser. If you create an account, your email, username and Argon2id password hash are stored on Nikita's server. Sign-in uses a necessary Secure, HttpOnly cookie for up to 30 days; it is not used for analytics. Public scores show your username only if you opt in. Optional analytics use a random tab-only ID and store coarse device, OS, country, page-time and feature counts. Session detail lasts 30 days; daily summaries last 396 days. Raw IPs and full browser strings are discarded. GitHub Pages and Google Fonts handle ordinary requests and may process or log IP addresses. Country lookup uses DB-IP Lite data on the server. Full privacy notice.
